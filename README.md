# 🧩 PixelWorld - 拼豆像素图案生成器

> 面向拼豆爱好者的在线像素图案转换工具，轻松将任何图片转换为精美的拼豆模版。

**在线体验：** [点击访问](https://tianmaohao.github.io/PixelWorld/)

---

## ✨ 功能特性

### 🎨 图片转换
- **拖拽上传** - 支持 JPG、PNG、GIF、WebP，最大 10MB
- **智能去背景** - 浏览器端 AI 抠图，自动移除背景保留主体
- **多种网格尺寸** - 经典 29×29 / 大尺寸 58×58 / 超大 116×116 / 圆形 / 心形
- **参数调节** - 亮度、对比度、饱和度、模糊实时预览
- **颜色量化** - Median Cut 算法，8-256 色可调
- **抖动算法** - Floyd-Steinberg / Atkinson，优化渐变效果
- **纯色模式** - 不限调色盘，完整还原图像颜色
- **内容感知裁剪** - 去背景后自动识别主体区域，不裁切

### ✏️ 像素编辑器
- **绘制工具** - 画笔、橡皮擦、取色器、区域填充
- **移动工具** - 拖拽平移画布
- **图层系统** - 多图层支持，独立显隐/锁定/透明度
- **画布交互** - Ctrl+滚轮缩放、空格拖拽、双击居中
- **辅助功能** - 网格线开关、颜色高亮、撤销/重做（50步）
- **快捷键** - B 画笔 / E 橡皮 / I 取色 / G 填充 / V 移动

### 📥 导出功能
- **像素预览图** - 带网格的 PNG 预览
- **拼豆模版图** - 带颜色编号，方便对照制作
- **纯色块图** - 无网格，适合直接打印
- **PDF 模版** - A4 尺寸，含图案 + 颜色对照表
- **全局导出** - 顶部导航栏随时可用

### 🎯 调色盘支持

| 品牌 | 系列 | 色数 | 说明 |
|------|------|------|------|
| 🎨 纯色模式 | - | 无限 | 最大还原图像颜色 |
| Artkal S | 2.6mm | 80 色 | 国产小豆，肤色渐变密集 |
| Artkal R | 5mm | 50 色 | 国产大豆，适合简单图案 |
| Perler Beads | 标准 | 40 色 | 美国品牌，欧美流行 |
| Hama Beads | 标准 | 43 色 | 欧洲品牌，北欧主流 |

## 🛠️ 技术栈

- **框架：** Vue 3 + TypeScript + Vite
- **UI 库：** Naive UI
- **状态管理：** Pinia
- **路由：** Vue Router 4
- **图片处理：** Canvas API（纯前端）
- **去背景 AI：** @imgly/background-removal（ONNX 浏览器端推理）
- **PDF 导出：** jsPDF
- **样式：** SCSS + CSS Variables

## 🚀 快速开始

```bash
# 克隆项目
git clone https://github.com/tianmaohao/PixelWorld.git
cd PixelWorld

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

启动后访问 `http://localhost:3000`

## 📸 使用流程

1. **上传图片** → 拖拽或点击上传，可选智能去背景
2. **调节参数** → 选择网格尺寸、颜色数量、调色盘品牌
3. **实时预览** → 右侧即时查看像素化效果
4. **导出下载** → 选择格式导出 PNG / PDF
5. **精细编辑** → 进入编辑器手动调整每个像素
